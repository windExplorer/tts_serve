# TTS_SERVE — 通用语音克隆服务

为 AstrBot 插件及其他调用方提供**统一 HTTP 接口**的本地语音克隆服务，支持多后端模型切换。

项目路径：`D:\AI\TTS_SERVE\tts_serve`

---

## 当前状态

- **主力模型（优先）**：`Qwen3-TTS-12Hz-0.6B-Base`
  - 用于替代 CosyVoice3；速度更快、延迟更低、Apache-2.0。
- **回退模型**：`Fun-CosyVoice3-0.5B-2512`
  - 保留兼容，便于 A/B 对比和回退。
- 对上层保持稳定的 HTTP 契约，切换模型时**调用方不用改代码**。

## 快速开始

1. 先看 [02-部署与操作指南.md](./docs/02-部署与操作指南.md) 的「Qwen3-TTS-0.6B 部署步骤」。
2. 跑通裸模型冒烟测试，确认音色/停顿/速度可接受。
3. 再实现服务适配层，保持 [HTTP 契约](./docs/02-部署与操作指南.md#1-统一-http-契约保持不变) 不变。
4. 用 [验收清单](./docs/02-部署与操作指南.md#53-验收清单) 做最终确认。
